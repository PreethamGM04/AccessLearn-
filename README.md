# AccessLearn — One Curriculum. Every Learner.

AccessLearn is an accessibility-first AI education platform that transforms one curriculum into inclusive learning experiences for different learners.

## Vision

> No student should be excluded from a lesson because the lesson wasn't designed for them.

## Core Idea

**Create once. Make accessible for everyone.**

A teacher uploads educational content, and AccessLearn uses AI to transform it into accessibility-oriented learning formats.

### Accessibility Targets

- 👁️ Visual accessibility — screen-reader-friendly content, image descriptions, and audio support
- 👂 Hearing accessibility — captions and accessible text
- 📖 Dyslexia-friendly learning — simplified reading mode, adjustable typography, spacing, and audio
- ♿ Motor accessibility — keyboard-friendly and simplified interaction

## MVP Features

- PDF content upload
- AI-powered educational content extraction
- AI-generated lesson structure
- Image descriptions
- Text-to-speech support
- Caption generation
- Dyslexia-friendly reading mode
- Screen-reader-friendly lesson presentation
